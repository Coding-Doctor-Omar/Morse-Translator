# Morse Code Translator

This is a simple text-based python Morse code translator that can convert text to Morse code and vice versa. Feel free to suggest any improvements.

## Usage Instructions
In this simple project, there is not much for you to worry about. Just run main.py and enjoy! Obviously, make sure you have Python set up on your computer :)

To navigate the menu, type the option number without any space and hit ENTER. You may see some "Note:..." message. Follow what it says in order to successfully have your message translated.
